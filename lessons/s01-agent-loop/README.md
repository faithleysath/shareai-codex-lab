# s01-agent-loop

这是 ShareAI 教程第一节 `s01` 的独立子项目目录。

当前阶段先保留一个最小 Bun + TypeScript 骨架，方便后续逐步实现教程中的 agent loop、工具调用和退出条件。

## 常用命令

安装依赖：

```bash
bun install
```

运行入口：

```bash
bun run start
```

开发模式：

```bash
bun run dev
```

## 当前文件

- `index.ts`：当前练习入口
- `package.json`：本节课自己的脚本和依赖
- `tsconfig.json`：本节课自己的 TypeScript 配置
- `bun.lock`：本节课自己的锁文件
